# 다크서울 (DARK SEOUL) — 레벨 디자인 문서

레벨 디자이너 **손석완**의 포트폴리오. 비에 잠긴 서울 도심을 무대로 한 소울라이크 스테이지 하나를 처음부터 끝까지 설계한 목업(Unreal Engine 5.8)의 레벨 기획서입니다.

- **보기:** https://sukwan123.github.io/dark-seoul-level-design/
- 개요 · 핵심 설계 원칙 · 인터랙티브 평면도(구역·객체 클릭 → 설명) · 측면도 · 3D 뷰어 · 긴장도 곡선
- 평면도·측면도·3D 형상은 레벨을 짓는 C++ 빌더의 좌표와 구운 목업 맵에서 그대로 뽑았습니다.
- 예시 이미지는 같은 레벨의 아트 패스 맵에서 촬영했습니다.

로컬에서 3D 뷰어까지 보려면 이 폴더에서 `python -m http.server` 로 열어 주세요(파일로 바로 열면 브라우저 보안 때문에 3D 형상이 안 뜰 수 있습니다).

3D 뷰어는 [three.js](https://threejs.org/) (MIT) r160 을 `assets/vendor/` 에 포함합니다.
